# Rangos Nobiliarios de Ondgard

Del más poderoso al menos poderoso:

| Rango                         | Papel                                                                                                               |
|-------------------------------|---------------------------------------------------------------------------------------------------------------------|
| **Emperador / Emperatriz**    | Soberano de un imperio, dominio que comprende varios reinos o pueblos bajo una única corona.                        |
| **Rey / Reina**               | Soberano de un reino. Autoridad suprema sobre todas las tierras de la corona.                                       |
| **Príncipe / Princesa**       | Heredero directo o miembro de la familia real.                                                                      |
| **Archiduque / Archiduquesa** | Gobierna una gran provincia estratégica en nombre de la corona. Raro, usado solo en los reinos más extensos (Voth). |
| **Duque / Duquesa**           | Señor de un ducado, vasta región con autonomía militar y judicial.                                                  |
| **Marqués / Marquesa**        | Gobierna una marca, territorio fronterizo con responsabilidades de defensa.                                         |
| **Conde / Condesa**           | Administra un condado, ciudad y tierras circundantes. El rango más común entre la alta nobleza.                     |
| **Vizconde / Vizcondesa**     | Lugarteniente del conde, gestiona una porción del condado.                                                          |
| **Barón / Baronesa**          | El rango nobiliario más bajo. Posee un feudo menor: un pueblo, una torre, un puesto de avanzada.                    |
