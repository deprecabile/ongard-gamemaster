# Ranghi Nobiliari di Ondgard

Dal piu' potente al meno potente:

| Rango                        | Ruolo                                                                                                         |
|------------------------------|---------------------------------------------------------------------------------------------------------------|
| **Imperatore / Imperatrice** | Sovrano di un impero, dominio che comprende piu' regni o popoli sotto un'unica corona.                        |
| **Re / Regina**              | Sovrano di un regno. Autorita' suprema su tutte le terre della corona.                                        |
| **Principe / Principessa**   | Erede diretto o membro della famiglia reale.                                                                  |
| **Arciduca / Arciduchessa**  | Governa una grande provincia strategica per conto della corona. Raro, usato solo nei regni piu' vasti (Voth). |
| **Duca / Duchessa**          | Signore di un ducato, vasta regione con autonomia militare e giudiziaria.                                     |
| **Marchese / Marchesa**      | Governa una marca, territorio di confine con responsabilita' di difesa.                                       |
| **Conte / Contessa**         | Amministra una contea, citta' e terre circostanti. Il rango piu' comune tra l'alta nobilta'.                  |
| **Visconte / Viscontessa**   | Luogotenente del conte, gestisce una porzione della contea.                                                   |
| **Barone / Baronessa**       | Il rango nobiliare piu' basso. Possiede un feudo minore: un villaggio, una torre, un avamposto.               |
